## Screenshot safety checklist

Before uploading a screenshot:

- Hide webhook URLs.
- Hide private execution URLs.
- Hide API keys, OAuth tokens, passwords, and credentials.
- Hide personal account information.
- Use synthetic data only.
- Do not include employer, client, customer, banking, production, or confidential information.
