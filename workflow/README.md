## Export safety checklist

Before uploading any workflow export:

- Remove API keys, OAuth tokens, passwords, and credentials.
- Remove private webhook URLs and private execution URLs.
- Remove personal account details.
- Remove employer, client, customer, banking, production, or confidential data.
- Confirm all examples use synthetic data only.
